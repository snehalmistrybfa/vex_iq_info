# VEX IQ First Robot Guide

A free, public, consolidated resource hub for 5th graders and families to build their first VEX IQ robot. Combines official VEX Robotics tutorials, Placer Robotics Academy curriculum, and the best community YouTube videos into one step-by-step path.

## What's inside

- **6-step path**: From unboxing the kit to competing in a tournament
- **Kit guide**: Every part in both boxes explained (with video walkthrough)
- **Build instructions**: BaseBot (first robot) + Flop (Level Up Hero Bot)
- **Game guide**: 2026-27 Level Up rules, manual, and reveal videos
- **Programming**: VEXcode IQ Blocks tutorials and video lessons
- **Placer Academy**: Full 9-topic curriculum map (login required for content)
- **Video library**: 20+ curated YouTube videos organized by category
- **Parts guide**: Interactive grid linking to official VEX usage guides

## Tech

Pure HTML/CSS/JS — no frameworks, no build step, no dependencies. Just open `index.html` in a browser.
