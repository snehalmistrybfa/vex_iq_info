The 6-Step Path: From Box to Competition

Follow these steps in order — each one builds on the last.

STEP 1 — WEEK 1

Unbox & Meet the Kit

Open the VEX IQ (2nd gen) kit, identify every part, charge the battery and controller, and pair the Brain to the Controller. Learn the names of beams, pins, gears, sensors, and motors so you can follow build instructions.

STEP 2 — WEEK 1-2

Build the BaseBot (Your First Robot)

Build the official BaseBot — a simple drivetrain robot that teaches chassis assembly, motor mounting, Brain installation, and wheel attachment. This is the foundation robot every VEX IQ student builds first. Use the 3D interactive instructions in your browser and follow along with the build video.

STEP 3 — WEEK 2-3

Drive It! Test the Built-in Drive Program

Before coding anything, use the Brain's built-in Driver Control program to drive your BaseBot with the Controller. This teaches you how the robot feels, turns, and moves. Practice driving straight, turning, and stopping — these are the skills you'll need for competition.

🎮 Run the Driver Control Program ↗ 🏆 Learn How a VEX IQ Competition Works ↗
STEP 4 — WEEK 3-5

Build "Flop" — the Level Up Hero Bot

The Hero Bot is the official starter competition robot for the 2026-27 season game "Level Up." Flop is designed to play the game and is competition-legal. Build it, drive it, and then modify it — that's what real teams do. The Hero Bot is a starting point, not the final robot.

STEP 5 — WEEK 4-6

Learn to Code with VEXcode IQ Blocks

Programming in VEX IQ uses drag-and-drop blocks (like Scratch). Start with the basics: configure your robot, make motors move, map controller joysticks, then add loops, conditions, and sensor reading. The goal is a robot that can do autonomous tasks (no driver) and respond to sensor input.

Meet the VEX IQ Kit

Two boxes make up one kit. Here's what's inside and how to get started.

📦 The kit comes in two snap-latch cases

Box 1 contains structural pieces: beams, plates, pins, connectors, angle pieces, standoff connectors, and the pin removal tool.

Box 2 contains electronics (Brain, Controller, battery, motors, sensors), motion parts (gears, sprockets, chain, shafts, wheels), and small hardware (jewel cases with specialty pins, cable retainers, string/spool kit).

There are no paper instructions in the kit — all build instructions are online and interactive (3D step-by-step). This is intentional: VEX updates instructions regularly and wants students to explore, not just follow one fixed build.

Box 1: Structural Pieces

The first case holds all the structural parts you'll use to build the robot's frame, chassis, and mechanisms.

Structure

Beams

1x, 2x, 2x4, 2x6, 2x8, 2x12, and 4x4 beams in various lengths. The backbone of every robot structure.

Structure

Plates

Flat plates for reinforcing structures, mounting electronics, and creating platforms.

Connectors

Pins & Capped Pins

The primary connector. Standard pins slide in; capped pins have a "hat" to stop them from going all the way through.

Connectors

Corner Connectors

90, 30, 45, and 60 degree angle connectors — color-coded by angle so you can find the right one fast.

Tools

Pin Removal Tool

New to the 2nd gen kit. Squeeze to grip pins for removal, pry pieces apart, or push pins out from the other side. Worth its weight in gold.

Structure

Standoffs & Connectors

Create space between beams for mechanisms. New 90-degree standoff connectors allow perpendicular connections.

Structure

Low-Profile Lock Beams

Compact beams with a lock hole for shafts — ideal for swing arms and tight spaces. You get 4 of these.

Structure

Angle Pieces & Crank Arms

Pre-made angle brackets and crank arms with integrated gears — perfect for building claws and linkages.

💡 Pro tip from the kit video

The angle connectors are color-coded by degree: look at the color to quickly find the 30, 45, or 60 degree angle you need. The number of degrees is also molded into the plastic.

Box 2: Electronics, Motion & Hardware

The second case holds the "brains" and "muscles" of the robot, plus all the motion components.

Electronics

IQ Brain (2nd gen)

The robot's computer. Color screen, 12 smart ports, built-in radio (no external radio needed), USB-C connection, backward compatible with 1st gen batteries.

Brain Menu Guide →
Electronics

IQ Controller (2nd gen)

Designed like an Xbox/PlayStation controller. Built-in rechargeable lithium-ion battery, USB-C charging, pairs wirelessly with the Brain.

Calibrate Controller →
Electronics

Robot Battery

Lighter than 1st gen. USB-C charging. Battery indicator shows charge level. Don't leave fully charged or fully empty for long storage.

Charging Guide →
Electronics

IQ Smart Motors

Same motors as 1st gen. Smart cables carry both power and data. Used for drivetrain, lifts, claws, and mechanisms.

Motor Guide →
Sensors

Distance Sensor

Laser-based distance sensor — precise directional measurement. Know exactly how far away objects are.

Sensor Overview →
Sensors

Optical Sensor

Detects colors accurately — new to the 2nd gen kit. Use it for sorting objects, following lines, or detecting game pieces.

Sensor Overview →
Sensors

Bumper Switch & Touch LED

Bumper switch detects physical contact (hit a wall, grab an object). Touch LED provides visual feedback and touch input.

Motion

Gears (12T, 24T, 36T, 48T)

Blue spur gears, color-coded by size. Tooth count is molded into the gear. All gears mesh together — mix sizes for gear ratios (speed vs. force).

Gears Guide →
Motion

Chain & Sprockets

New to the 2nd gen kit. Orange sprockets (visually distinct from blue spur gears). Use with chain for long-distance power transfer.

Motion

Shafts (Color-Coded)

Plastic shafts are color-coded by length (orange, blue, green). New metal shafts, cap shafts, and catch shafts for durability. Motor shafts have a green collar.

Shafts Guide →
Motion

Wheels

Omni-directional wheels (for multi-directional movement) and balloon/traction wheels (for grip). Wheels come pre-assembled.

Wheels Guide →
Motion

Spool & String Kit

New part! Wind string onto the spool to create a winch/lift mechanism. Strong string with pin-attachable ends.

Hardware

Smart Cable Retainers

Clip smart cables to the robot frame to keep them tidy and out of the way of mechanisms. New to 2nd gen.

Hardware

USB-C Cable

One cable for everything: charge the Controller, charge the Brain battery, and connect the Brain to a computer for programming.

💡 Pro tip from the kit video

Orange parts = sprockets (use with chain). Blue parts = spur gears (use with gears). This color coding helps students avoid trying to mesh a sprocket with a spur gear, which doesn't work.

🛠️ Build tips from the Placer Robotics Academy

  • Build one short section at a time and ask a teammate to check it against the picture before moving on.
  • Join parts correctly — choose the right pin type, don't force parts. If it doesn't go in smoothly, check the orientation.
  • Make it strong and square — use beams, plates, corners, and two-point connections. A wobbly robot falls apart.
  • Check motion before powering on — spin gears and wheels by hand first. If something rubs or binds, fix it before turning on the motors.
  • Route cables carefully — use smart cable retainers to keep wires away from gears and wheels. Keep the battery and Brain reachable for swaps.
  • Compare ideas with quick trials — build a small test of each mechanism and use the same test for each one. Data beats opinion.

Programming with VEXcode IQ Blocks

Drag-and-drop coding — no typing required. Start here if you've never programmed before.

🎯 What you'll learn (Placer Academy Topic 5)

The Placer Academy breaks programming into 8 sub-skills, in order:

  • Open VEXcode IQ — start a Blocks project for the correct IQ Brain generation
  • Tell code what is connected — configure motors, drivetrain, and sensors with the ports on the real robot
  • Make a sequence — download, run, stop, and change a short motion sequence
  • Make driver controls — map Controller inputs and compare drive configurations
  • Repeat and decide — use events, loops, conditions, and simple variables
  • Let the robot sense — read sensor data and use one value in code
  • Build a repeatable skills path — plan, measure, and repeat a short autonomous path
  • Find a code problem — check hardware, firmware, configuration, data, and code in order
