Build tips from the Placer Robotics Academy

  • Build one short section at a time and ask a teammate to check it against the picture before moving on.
  • Join parts correctly by choosing the right pin type and checking orientation instead of forcing parts.
  • Make it strong and square with beams, plates, corners, and two-point connections.
  • Check motion before powering on by spinning gears and wheels by hand first.
  • Route cables carefully so wires stay away from gears, wheels, and arms.
  • Compare ideas with quick trials using the same test for each mechanism.

30-Day Curriculum

Six phases from game detective to tournament-ready. Each day starts with a puzzle, makes you think, then teaches you exactly what you need.

How This Works

Every day follows the same rhythm: Hook (a puzzle that makes you curious) → Think First (write your guess) → Concepts (the vocabulary) → Learn (watch videos) → Connect (the aha moment) → Try It (hands-on challenge) → Reflect (deepen understanding).

You won't get answers spoon-fed. You'll discover them. That's how real engineers think.

0 of 30 days complete

Hook

Two robots each move four Bean Bags. One earns far more points, while the other finishes sooner. How could both outcomes be sensible—and what would you need to know before designing either robot?

Think First

Before watching, sketch the field from memory and write three facts you think determine a winning score. Circle every fact you are unsure about.

Concepts

  • reading a game reveal critically
  • manual as source of truth
  • scoring breakdown
  • one-object possession
  • time, distance, accuracy, and goal-height tradeoffs
  • teamwork versus skills
  • turning game requirements into robot jobs

Learn

  1. Level Up Game Reveal — VEX Robotics
  2. Game Manual Breakdown — RoboSTEM
  3. Level Up Worlds Reveal — VEX Robotics
  4. Current Level Up Game Manual — verify the latest rules before teaching

Connect the Dots

A robot is not "good" in isolation; it is good at valuable game jobs under rules and time pressure. Higher goals promise more points but demand reach, stability, placement accuracy, and travel time, so the first design tool is a requirement-and-risk list, not a pile of parts.

Try It

Make a one-page "Team 295U Game Detective" sheet with columns for Job, Points/benefit, Difficulty, Robot feature needed, and Rule to verify. Add at least five jobs, then choose one as the first reliable scoring goal. Do not optimize yet.

1 Beginner: lists jobs without evidence
2 Developing: connects five jobs to scoring/manual facts and identifies uncertainties
3 Proficient: compares value, time, and risk, cites rule sections, and defends a first-goal choice while naming what test could change the decision.

Reflect

  • What if a low goal can be scored twice as reliably as a high goal—what data would decide which is better?
  • Which sentence in the manual changed one of your original guesses?
Coach note: Level Up rules can change during the season. Check the current official manual and Q&A before teaching this day.

Connect the Dots
